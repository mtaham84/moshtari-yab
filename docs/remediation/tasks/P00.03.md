## ۱. شرح و هدف اجرا
در این تسک، محیط تست مستقل، تکرارپذیر و همگام با CI برای اجرای هر دو رانر Pytest و Django آماده‌سازی و سنجش شد:
1. استفاده از پایتون هدف CI یعنی Python 3.12.16 درون داکر کانتینر پروژه به جای نسخه‌های متغیر هاست.
2. ایزوله‌سازی پوشه‌های موقت تست‌ها به `/tmp` (`--basetemp=/tmp/pytest -o cache_dir=/tmp/.pytest_cache` و جایگزینی `settings.BASE_DIR` در تست‌های بررسی پست با `tempfile.gettempdir()`) برای رفع خطاهای Permission Denied.
3. تنظیم صریح پایگاه داده PostgreSQL 16 به همراه pgvector.
4. اجرای مستقل رانرها، ثبت آمار تفکیک‌شده و علل skipها بدون جمع کورکورانه آمارها.

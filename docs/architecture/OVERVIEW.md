# System overview

The default Compose stack is PostgreSQL, panel, sync, need engine, and Telegram crawler (docker-compose.yml:28-88). X, retention reporting, and Xray need profiles; Instagram has no Compose service (docker-compose.yml:90-128). Roles map to commands in docker/entrypoint.sh:23-68.

| Package | Purpose, process, and caller | Reads and writes today |
|---|---|---|
| apps/ | Django panel. web serves pages; sync imports engine results (docker-compose.yml:44-72, docker/entrypoint.sh:24-40). | Reads/writes Django public tables for businesses, products, billing, communities, and opportunities (apps/businesses/models.py:5-119, apps/products/models.py:6-286, apps/billing/models.py:12-122, apps/discovery/models.py:169-252, :583-804). Reads collector/engine schemas via apps/discovery/engine_bridge.py:243-261; reads X status and retention report files (apps/billing/services.py:501-548). |
| need_engine/ | Buyer need extraction and product matching. Compose engine runs python -m need_engine run (docker/entrypoint.sh:41-45). It reads the archive/catalog, not Instagram (need_engine/sources.py:64-162). | Reads crawler.tg_messages, crawler.x_posts, crawler.x_post_products, and Django catalog/access/style/billing tables (need_engine/sources.py:64-162, need_engine/config.py:84-109). Creates/writes queue, vectors, needs, costs, published opportunity state in its configured schema (default need_engine; need_engine/store.py:29-65, :490-499). |
| telegram_crawler/ | Telegram archive process. Compose crawler calls telegram_crawler.main (docker/entrypoint.sh:46-58). | Reads Telegram API/session, group links, panel communities; writes crawler.tg_users, tg_chats, tg_messages, collector_heartbeats (telegram_crawler/main.py:65-100, telegram_crawler/db.py:37-51, telegram_crawler/schema.sql:9-90). |
| workers.x_collector/ | Experimental X collector. Compose profile x runs it (docker-compose.yml:90-96, docker/entrypoint.sh:60-64). | Reads X CLI auth, product queries, SQLite state; writes JSONL/status, then calls x_ingest if auto-ingest is on (workers/x_collector/worker.py:144-168, :174-270, :354-409). |
| x_ingest/ | Loads X JSONL; called by workers.x_collector.ingest_new or python -m x_ingest (workers/x_collector/worker.py:377-409, x_ingest/__main__.py:169-190). | Reads JSONL; writes crawler.x_posts, x_post_products, x_search_runs (x_ingest/__main__.py:75-164). |
| workers.ig_collector/ | Experimental manual Instagram collector CLI (workers/ig_collector/cli.py:29-46); no Compose caller. | Reads seeds/backend; writes post/comment/seller-lead JSONL, status, SQLite state (workers/ig_collector/worker.py:183-210, :491-568). No panel or engine table writes. |
| instagram_discovery/ | Separate OpenCLI/Agent Reach discovery and labeling CLI, not started by Compose (instagram_discovery/collector.py:23-69, instagram_discovery/cli.py:87-100). | Reads source/category JSON and OpenCLI results; writes timestamped post/review JSONL or label CSV (instagram_discovery/cli.py:148-167, :75-100). It does not read comments or write to Django (:173). |
| shared/ | Shared record, JSONL, state, status, heartbeat, and X-filter helpers called by collectors/engine (docs/architecture/dependency-graph.md). | Writes collector files and state tables (shared/collector_kit/jsonl.py:11-36, shared/collector_kit/state_store.py:54-82); heartbeat table is <TG_DB_SCHEMA>.collector_heartbeats, default crawler (shared/collector_kit/heartbeat.py:14-18, :37-82). |
| xray/ | Optional Compose proxy under profile proxy; separate CLI/daemon utility (docker-compose.yml:120-128, xray/proxy_switcher.py:642-851). | Reads xray/config.json and proxy links; may write active config or install systemd service (xray/proxy_switcher.py:291-309, :448-504, :690-807). |
| config/ | Django settings and WSGI/ASGI startup, loaded by panel and management commands (config/wsgi.py:1-8, config/asgi.py:1-8). | Reads .env/environment, configures PostgreSQL and Django (config/settings.py:1-24, :112-181); owns no application data tables. |

Telegram flows through archive into engine and panel; X flows JSONL → x_ingest → engine → panel (telegram_crawler/schema.sql:61-90, need_engine/sources.py:64-162, apps/discovery/management/commands/sync_opportunities.py:30-58). Instagram stops at local files/state (workers/ig_collector/worker.py:491-568, instagram_discovery/cli.py:159-174).

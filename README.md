# مشتری‌یاب (Moshtari-Yab)
> **سامانه هوشمند کشف مشتری بالقوه در جوامع آنلاین (مسابقه buildX)**  
> *AI-Powered Customer Discovery Workspace for Online Communities*

«مشتری‌یاب» یک پلتفرم ایجنتیک است که به کسب‌وکارها کمک می‌کند تا با تحلیل هوشمند مکالمات و پیام‌های ردوبدل‌شده در جوامع آنلاین (نظیر گروه‌های تخصصی تلگرام، توییتر/ایکس، فروم‌ها و شبکه‌های اجتماعی)، افرادی را که نیازمند محصولات یا خدمات آن‌ها هستند بیابند، نیاز آن‌ها را ارزیابی و تطبیق دهند، امتیاز شایستگی آن‌ها را محاسبه کنند و پیش‌نویس ارتباطی شخصی‌سازی‌شده تولید نمایند.

## ✨ ویژگی‌های کلیدی

### ۱. کنسول نئومورفیک سنگی و رادار آبسیدین (Stone & Obsidian Console)
- **شاسی سنگی معلق (Floating Stone Chassis)** با پس‌زمینه معماری شیاردار ۴۵ درجه و سایه‌های دوگانه نرم و ارگونومیک نئومورفیسم.
- **نوار ریل متصل مراحل فرآیند (Pipeline Stepper Rail Track)** برای نمایش گام‌به‌گام فرآیند کشف:
  $$\text{۱. رصد جوامع} \longrightarrow \text{۲. فیلتر نیاز} \longrightarrow \text{۳. تطبیق کالا} \longrightarrow \text{۴. کیفیت و هزینه} \longrightarrow \text{۵. پیش‌نویس ارتباط}$$
- **ماژول رادار زنده کشف مشتری آبسیدین (`#111420`)**:
  - نوار شنود زنده پیام‌ها با پالس موج صوتی (Audio Waveform).
  - رادار نقشه‌ای با پرتو اسکن دورانی (`sweep beam`) و پینگ‌های تعاملی تلگرام و توییتر.
  - پیش‌نمایش فوری فرصت شناسایی‌شده، بیان دلیل خرید، محاسبه توکن مصرفی و هزینه تحلیلی دلاری/تومانی، به همراه متن پیش‌نویس پیام و دکمه کپی سریع.
- **تایپوگرافی اصیل وزیرمتن (Vazirmatn)** و انطباق کامل با زبان فارسی و راست‌چین (RTL).
- **سوئیچ سه‌حالته پوسته (Theme Switcher)**: روشن، تاریک و خودکار سیستم.

### ۲. احراز هویت دوگانه و امنیت (Dual Authentication)
- ورود مستقیم با رمز عبور و پشتیبانی همزمان از ورود بدون رمز عبور با کد تأیید ۶ رقمی ایمیل (OTP).
- مکانیزم محدودیت نرخ درخواست (Rate Limiting) و قفل موقت بعد از ۵ تلاش ناموفق.

### ۳. پایگاه دانش کاتالوگ محصولات و سیستم گالری چندگانه
- دسته‌بندی سلسله‌مراتبی (Hierarchical Categories) برای کالاهای فیزیکی و خدماتی.
- ثبت ویژگی‌های ساختاریافته (JSON Attributes) و تعریف پرسونای خریدار ایده‌آل (ICP).
- **سیستم مدیریت گالری تصاویر**:
  - سقف ۱۰ تصویر به ازای هر محصول با اعتبارسنجی سمت کاربر و سرور.
  - پیش‌نمایش زنده در کلاینت قبل از ذخیره.
  - انتخاب و تغییر پویای «تصویر اصلی».
  - حذف ایمن تصویر با قابلیت ارتقای خودکار نخستین تصویر باقی‌مانده به عنوان تصویر اصلی.

### ۴. شفافیت هزینه و کیفیت تحلیل (buildX Requirement)
- محاسبه و نمایش صریح تعداد توکن‌های مصرفی و هزینه دلاری و تومانی به ازای تحلیل هر پیام.
- نمره شایستگی کیفی فرصت (امتیاز ۰ تا ۱۰۰) همراه با استدلال تحلیلی ایجنت.

### ۵. پایگاه داده تمیز و فید اولویت‌بندی شده برای توسعه‌دهندگان ایجنت (Agent Data Architecture)
- دسترسی سریع و تمیز به داده‌های کاتالوگ از طریق سرویس پایتون `get_agent_discovery_feed()` و اندپوینت REST API مسیر `GET /discovery/api/agent/feed/`.
- پشتیبانی از **ساختار درختی تا ۵ سطح** (`Level 1` تا `Level 5`) همراه با زنجیره کامل اجداد (`ancestors`) و مسیر کامل شاخه.
- **ویژگی‌های دلخواه نامحدود محصول (Dynamic Custom Attributes)**: ذخیره‌سازی کلید-مقدار (سایز، رنگ، جنس، مدل، گارانتی و...) برای تطابق دقیق با نیازهای کاربران در شبکه‌های اجتماعی (+10% تقویت اعتماد به ازای هر تطابق).
- **سیستم اولویت‌بندی ۵ سطحی (`discovery_priority`)**: از ۱ (عادی) تا ۵ (فوری و پایش حداکثری) همراه با ضرایب اسکن هوشمند (`scan_weight`).
- **سهمیه روزانه پایش ۵۰ کالا** به همراه ارسال مستقیم پیام هوشمند از اکانت‌های رسمی فروشنده در تلگرام و X بدون نیاز به تأیید پیش‌نویس.
- 📖 **مستندات کامل ویژه مهندسان ایجنت:** فایل [AGENT_DATA_GUIDE.md](AGENT_DATA_GUIDE.md) را مطالعه فرمایید.

## 🛠 فناوری‌های استفاده‌شده (Tech Stack)

- **Backend**: Python 3.12, Django 5.x / 6.x
- **Database**: SQLite (توسعه محلی) / PostgreSQL (محیط عملیاتی)
- **Frontend**: Django Templates, Semantic HTML5, Vanilla JavaScript, CSS3 Neumorphism
- **Design System**: Stone & Obsidian Neumorphic System, Vazirmatn Typography
- **Imaging**: Pillow

## 🚀 راه‌اندازی و اجرای محلی

### پیش‌نیازها
- Python 3.12 یا بالاتر
- محیط مجازی (`venv`)

```bash
# ۱. کلون ریپازیتوری
git clone <repository_url>
cd customerweb

# ۲. ایجاد و فعال‌سازی محیط مجازی
python3 -m venv .venv
source .venv/bin/activate

# ۳. نصب وابستگی‌ها
pip install -r requirements.txt

# ۴. تنظیم متغیرهای محیطی
cp .env.example .env

# ۵. اعمال مایگریشن‌های دیتابیس
python manage.py migrate

# ۶. اجرای سرور توسعه
python manage.py runserver
```

مرورگر خود را باز کرده و به آدرس `http://127.0.0.1:8000` مراجعه فرمایید.  
حساب آزمایشی پیش‌فرض: `seller@moshtariyab.com` با رمز `demo123456`.

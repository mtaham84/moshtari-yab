# analysis — ایجنت تحلیل مشترک مشتری‌یاب

مستقل از منبع: هر خزنده پیام را به `SocialMessage` تبدیل و در `AnalysisStore` (صف SQLite) می‌گذارد؛
`python -m analysis.worker run` قیف فیلتر ← غربال ← تحلیل عمیق را اجرا و نتیجه و هزینه هر پیام را ثبت می‌کند.

راهنمای کامل: `docs/MILESTONE_1.md` و `docs/MILESTONE_2.md`.
